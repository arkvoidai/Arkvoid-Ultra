# ARKVOID

Original persistent cultivation-fantasy open-world game. Browser runtime: Vite + strict TypeScript + Three.js.

## Run

```bash
nvm use            # Node 22
npm install        # generates package-lock.json — commit it
npm run dev        # play at http://localhost:5173
npm run check      # typecheck, lint, format, tests, cycle check
npm run build
```

## Controls

Click the canvas to capture the mouse. `WASD` move, `Shift` run, `Space` jump, mouse look. Arrow keys also rotate the camera. `Esc` releases the mouse.

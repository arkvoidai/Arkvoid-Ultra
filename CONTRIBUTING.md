# Contributing to ARKVOID

1. Read [AGENTS.md](AGENTS.md) and the relevant constitutions.
2. Branch from the current `main`.
3. Keep the change focused on a player-visible capability or an explicit engineering enabler.
4. Add or update tests for deterministic logic and state transitions.
5. Run `npm run verify`.
6. Update the progress ledger when scope or completion status changes.
7. Open a pull request with implementation evidence, validation results, and an honest list of placeholders.

Do not merge claims of world streaming, AI NPCs, persistence, multiplayer or final art without the corresponding implementation and evidence.
